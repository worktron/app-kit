# web/

web/ web apps (app-kit/web): the MUI theme for each look (theme.ts, lookTheme), fetch wrapper, connection, new build, preload reload, error boundary and its reload after a crash, saved copies, row links, how long ago (age.ts, with no React, also app-kit/web/age, and now.ts, useNow), hover intent (hover-intent.ts), when the pointer may light, select or focus, with the menu bar theme's PointerIntent.swift held to its numbers by test/hover-intent-swift.test.ts, the phone's Text Size, fields that never zoom, pull to refresh, the font wait, the sign-in gate and the provider interface it takes (sign-in/provider.ts), and the iPhone sign-in it takes (sign-in/iphone-sign-in.ts), which tauri/iphone-sign-in makes, so nothing under web/ imports Tauri; first-paint.js, the Vite plugin for the first frame (app-kit/web/first-paint); push/, notifications for a web app on a phone's Home Screen: the page half (page.ts, in app-kit/web), the notification worker (worker.js, a classic script checked by its own tsconfig.json under the service worker's types), the Vite plugin that serves it (vite.js, app-kit/web/push/vite), the server's sending (server.ts, app-kit/web/push/server), and the names they share (names.ts); server.ts, the server's sending of the built page (app-kit/web/server), which the fixture's server (e2e/serve.ts) uses, with an app's public pages, which public-pages.tsx writes at build as finished HTML (app-kit/web/public-pages); playwright-webkit.js, Playwright's WebKit run from a copy macOS keeps out of the Dock (app-kit/web/playwright-webkit); playwright-offline-audio.js, a test page's Web Audio on the browser's offline engine, so no speaker opens, and Playwright's test with it on every context (app-kit/web/playwright-offline-audio); playwright.js, the browser test steps every app shares (app-kit/web/playwright); drive.ts, `app-kit web drive`, the app driven headless from a steps file for persona walk-throughs and store screenshots, run against a page of its own by web/e2e/drive.e2e.ts; web/e2e/fixture, a small app built on the kit, run built in a hidden Chromium; web/e2e/audio-output.swift, the record of which processes have an output device open, for offline-audio.e2e.ts
