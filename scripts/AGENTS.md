# scripts/

scripts/ the gates (gates.sh), and the landing (land-main.sh, which runs land.ts), which sets the version, writes each change's Urgency and Apps lines into CHANGES.md, tags it, and on a release marked now names the apps on this machine on an older version and starts urgent-tickets.ts, which files one app-kit-catch-up ticket in each; owed.ts, what one app owes the kit, made for metamax's landing of the app to run, which holds once a release asking something of it is more than 14 days old; apps.ts, which reads every app on the kit for the apps report (.claude/skills/apps-round, the page of where each app stands, run when the owner asks, since each app keeps itself current) and for that urgent list, and kit-features.ts, the kit's features an app should have once it takes their piece, which apps.ts reads to say which of them each app lacks
