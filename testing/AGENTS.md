# testing/

testing/ what every kind's tests share: start-up.ts (app-kit/testing/start-up), the test start-up file a project names in bunfig.toml's preload, which the kit's own bunfig.toml names too; playwright-dock.js (app-kit/testing/playwright-dock), a Playwright browser run from a copy macOS keeps out of the Dock, which web/playwright-webkit.js and the extension harness use; forget-apps.js (app-kit/testing/forget-apps), which deletes a Mac app or a folder holding one and has macOS forget each, which the start-up file, the Dock copy, every test that makes an app in a temporary folder and tauri/built-apps.ts use; test/applications.ts watches macOS's application list for the Dock tests, web/e2e/dock.e2e.ts and extension/e2e/dock.e2e.ts
