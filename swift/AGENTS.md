# swift/

swift/ Mac apps built in Swift: menu-bar/, the menu bar theme, a Swift package an app builds from the kit bun installed: Sources/MenuBarTheme (the two looks, plain and console, and their tokens, the bundled JetBrains Mono in Fonts/ for the console look, the pieces, the panel and the snapshot, and in the plain look a window's pieces, Window.swift, the switch, the menu and the field, Controls.swift, and one window with a side column, SideWindow.swift: the window that remembers its place, the column's rows and a row's button), Sources/menu-bar-snapshots (the Studies screens drawn in either look, and compared in the console look, and WindowCheck.swift, the real window made off screen in each case a saved place can leave it), Tests/, and e2e/ (the mockups, the comparison with a headless Chromium, the bare swiftc build, and same-renders.sh, the check that every sample draws byte for byte as on a given commit) window-recording/, the program that makes a display nobody sees and records one window on it (ScreenCaptureKit), built by Swift's package manager only, by command-line/window-recording.ts; mac-app/, what every Swift Mac app writes for itself, a Swift package built the same way: Sources/MacApp (the log, launch at login, the Dock icon while a window is open and opening Settings, the native messaging host, the build's version and commit, the refresh on a clock and after wake, and a program run with a time limit), Tests/, and e2e/ (the bare swiftc build)

## Rules for agents working here

- A Swift piece is a Swift package in its own folder (`swift/menu-bar/`, `swift/mac-app/`), which an Xcode app adds as a local package from the kit bun installed and a bare swiftc build compiles as a module of its own, so `package.json` stays the one place that names the kit's version. Its tests are Swift tests in its own `Tests/`, since Swift's package manager reaches no file outside the package, and its build state (`.build/`) is ignored. Nothing it draws or tests opens on the screen: the theme's tests set `MenuBarPanel.staysOffScreen` and draw through `snapshot`, and the Mac app package's pass stand-ins for the login item, the Dock and every folder, which `StaysOffTheMachineTests` holds.
