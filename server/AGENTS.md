# server/

server/ server-only pieces no kind of app owns: google/ (what a refusal from Google means, with no React, and demo.ts with demo-command.ts, `app-kit google demo-reset` and `demo-grant`, a demo account's inbox and calendar set for an app's verification and demo videos), postgres/ (the database opener on Drizzle: Postgres from a postgres:// URL, PGlite otherwise, and the migrated in-memory databases for tests; test/fixtures/postgres holds the tests' schema and migration), start/ (the Hono app every server starts from, with its health route, request log, JSON errors and refusal of writes other websites send, and listen, which serves it and stops it cleanly; web/e2e/serve.ts runs on it), every/ (a job on a clock that never runs twice at once, with no imports, app-kit/server/every), process-usage/ (one reading of a macOS process's CPU time, memory and disk, finished child processes included, through bun:ffi opened only at the first reading, and in window.ts `ps`'s parser and the cores each process used between two readings of the machine, app-kit/server/process-usage), amazon-orders/ (reading Amazon's order pages from their HTML, on happy-dom, the only file that imports it, app-kit/amazon-orders; test/fixtures/amazon-orders holds the tests' made-up pages), amazon-cart/ (reading one store's Amazon cart page, which throws on a page that is not that store's cart, and a product's page into the request that adds one to a cart, which throws on a page that is not that product's, through amazon-orders' parse, app-kit/amazon-cart; test/fixtures/amazon-cart holds the tests' made-up pages, and its README what marks each store's cart and a product's page, and what is not yet known)
